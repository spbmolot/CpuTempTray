CPU Temp Tray — аппаратная температура CPU
==========================================

Версия для Windows 10/11 x64.

Что показывает
--------------
Программа читает реальный цифровой датчик процессора через LibreHardwareMonitor:
  1. Core Max — приоритет (самое горячее ядро);
  2. CPU Package — если Core Max недоступен.

Windows thermal zone / ACPI больше НЕ используется.

Первый запуск
-------------
1. Если папка скачана из интернета, снимите блокировку с файлов, иначе .NET
   откажется загружать LibreHardwareMonitorLib.dll:
       powershell -Command "Get-ChildItem <папка> -Recurse | Unblock-File"
2. Запустите CpuTempTray.exe от имени администратора.
3. Если PawnIO ещё не установлен, программа предложит его установить.
   Нажмите «Да» и подтвердите стандартный запрос UAC.
4. После этого в системном трее появится реальная температура CPU.

Права администратора
--------------------
Обязательны. Чтение цифрового датчика идёт через MSR процессора, доступ к
которым даёт драйвер PawnIO, а он требует повышения прав. Без администратора
список датчиков виден, но все значения пустые и в трее остаётся серое «--».

PawnIO_setup.exe взят без изменений из официального релиза исходников
LibreHardwareMonitor v0.9.6. Он нужен для безопасного низкоуровневого чтения
Intel MSR и устанавливается один раз.

Цвет значка
-----------
  зелёный    < 60 °C
  оранжевый  60–79 °C
  красный    >= 80 °C
  серый --   аппаратный датчик недоступен

Обновление: раз в 2 секунды.
Наведение на значок показывает источник: Core Max или CPU Package.
Правый клик: автозапуск с Windows / выход.

«Start with Windows» создаёт задание Планировщика «CpuTempTray» с триггером
на вход в систему и флагом «Выполнить с наивысшими правами». Ключ реестра
HKCU\...\Run для этого не годится: запуск оттуда идёт без повышения прав.
Переключение пункта меню само требует прав администратора.

Безопасность
------------
- приложение не использует сеть и ничего никуда не отправляет;
- драйвер ставится только после явного подтверждения пользователя;
- используется LibreHardwareMonitor 0.9.6 и PawnIO из официального проекта;
- EXE CpuTempTray не подписан цифровой подписью, поэтому SmartScreen может
  показать предупреждение для нового неизвестного приложения.
